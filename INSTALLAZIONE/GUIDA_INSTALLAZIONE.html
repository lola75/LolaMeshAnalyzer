📥 Software da Installare

Per usare tutte le funzioni del progetto servono Node.js/npm per l'interfaccia e Python per il server mesh locale.

✅ Node.js (OBBLIGATORIO)

Versione consigliata: LTS supportata, 20 o superiore

Perché: Node.js include npm, il gestore di pacchetti di cui l'app ha bisogno.

Download: nodejs.org/en/download - scarica la versione LTS.

Nota: npm viene installato automaticamente con Node.js

✅ Python (OBBLIGATORIO per server MeshLib)

Versione consigliata: Python 3.11 a 64 bit

Download: python.org/downloads/windows

Durante l'installazione seleziona Add Python to PATH e includi Python Launcher (py).

🚀 Guida di Installazione Passo per Passo

1

Scarica e Installa Node.js

  1. Apri il browser e vai su https://nodejs.org
  2. Seleziona la versione LTS (Long Term Support)
  3. Clicca su "Download for Windows"
  4. Quando il file è scaricato, fai doppio clic per aprire l'installer
  5. Clicca Next per accettare i termini di utilizzo
  6. Clicca Next per selezionare la cartella di installazione (mantieni il default)
  7. Assicurati che "npm package manager" sia selezionato
  8. Clicca Install e attendi il completamento
  9. Clicca Finish

⚠️ Importante: Riavvia il PC dopo l'installazione per completare la configurazione.

2

Verifica l'Installazione

Apri PowerShell (o il Terminale) e digita i seguenti comandi:

node --version
npm --version

Dovresti vedere un numero di versione (es: v18.15.0). Se vedi un errore, riavvia il PC e riprova.

3

Scarica/Copia il Progetto

Assicurati di avere la cartella del progetto nel tuo PC. Nei comandi seguenti sostituisci il percorso di esempio con quello effettivo:

C:\percorso\Analizzatore di mesh

Se non ce l'hai ancora, puoi:

  • Clonare da Git: Se il progetto è su GitHub
  • Copiare il file ZIP: Se l'hai ricevuto come archivio
  • Copiare la cartella: Se ce l'hai su un'altra unità
4

Installa le Dipendenze

Apri PowerShell e naviga nella cartella del progetto:

cd "C:\percorso\Analizzatore di mesh"

Ora installa tutte le dipendenze necessarie:

npm ci

⏳ Questo potrebbe richiedere 2-5 minuti. Non interrompere il processo!

Nota: Vedrai molte linee di output nel terminale. Questo è normale. Se vedi errori rossi alla fine, potrebbero essere solo avvisi, non errori critici.

5

Installa il server Python, MeshLib e ITK

Da PowerShell aperto nella cartella principale del progetto, crea l'ambiente Python e installa i pacchetti:

py -3.11 -m venv ".\mio server\.venv"
& ".\mio server\.venv\Scripts\python.exe" -m pip install --upgrade pip
Push-Location ".\mio server"
& ".\.venv\Scripts\python.exe" -m pip install -r requirements.txt
Pop-Location

MeshLib viene installata dal file wheel Windows x64 incluso in mio server. Per l'uso ITK il backend installa SimpleITK. Il file requirements.txt raccoglie anche FastAPI, Uvicorn, python-multipart, NumPy e Open3D.

Se py -3.11 non è disponibile, installa Python 3.11 a 64 bit dal link ufficiale riportato sopra e riapri PowerShell.

6

Avvia l'Applicazione

Avvia il backend in una finestra PowerShell:

.\mio server\run_server.bat

Apri una seconda finestra PowerShell nella cartella del progetto e avvia il frontend:

npm run dev

Cosa succede ora:

  • Il backend mesh risponde su http://127.0.0.1:8000 (controllo: /health)
  • Vite mostrerà un URL simile a: Local: http://localhost:5173
  • Apri il browser (Chrome, Edge, Firefox, ecc.)
  • Vai su http://localhost:5173
  • L'applicazione dovrebbe aprirsi! 🎉

⚡ Opzioni di Avvio Rapido

Una volta installato, hai questi modi per avviare l'app:

Comando Descrizione URL
npm run dev Modalità sviluppo con reload automatico http://localhost:5173
npm run local Alternativa a npm run dev http://localhost:5173
npm run build && npm run preview Build di produzione + preview locale http://localhost:4173
npm run electron-dev App desktop Electron Applicazione nativa
npm run start Build + Server di produzione http://localhost:3000

🎯 Metodi di Avvio Alternativi

Tramite File Batch (Scelta Rapida)

Se nella cartella del progetto esiste il file AvviaApp.bat, puoi usarlo per avviare l'app con un doppio clic. Questo è il modo più semplice per gli utenti non tecnici.

  1. Vai nella cartella del progetto
  2. Fai doppio clic su AvviaApp.bat
  3. Si aprirà una finestra del Terminale e quindi il browser

Creare un Collegamento Rapido

Per rendere ancora più semplice l'avvio:

  1. Clicca con il tasto destro su AvviaApp.bat
  2. Seleziona Invia a → Desktop (crea collegamento)
  3. Ora hai un'icona sul desktop per avviare l'app!

❌ Risoluzione dei Problemi

Problema: "npm: il termine non è riconosciuto"

Soluzione:

  • Assicurati di aver installato Node.js
  • Riavvia il PC completamente
  • Riapri PowerShell
  • Digita di nuovo: npm --version

Problema: Port 5173 già in uso

Soluzione:

  • Un'altra istanza dell'app è già in esecuzione
  • Chiudi il terminale precedente
  • Aspetta qualche secondo
  • Prova di nuovo con npm run dev

Problema: Errore durante "npm install"

Soluzione:

  • Controlla la connessione a internet
  • Non cancellare package-lock.json; dalla cartella del progetto ripeti npm ci

Problema: L'app non si apre nel browser

Soluzione:

  • Il terminale dovrebbe mostrarti un URL (es: http://localhost:5173)
  • Copia l'URL e incollalo manualmente nel browser
  • Se ancora non funziona, il server potrebbe non essere avviato correttamente
  • Controlla che nel terminale non ci siano errori rossi

📝 Checklist di Verifica

  • Node.js è installato (verifica con node --version)
  • npm è disponibile (verifica con npm --version)
  • La cartella del progetto esiste e contiene package.json
  • Hai eseguito npm ci senza errori critici
  • Hai creato mio server\.venv e installato requirements.txt
  • Il backend risponde a http://127.0.0.1:8000/health
  • Il comando npm run dev avvia il server senza errori
  • Il browser si apre all'indirizzo http://localhost:5173
  • L'interfaccia grafica dell'app carica correttamente

💬 Supporto e Contatti

  • Controlla i log del terminale: Spesso gli errori forniscono indizi utili

  • Riavvia il PC: Molti problemi si risolvono con un riavvio completo
